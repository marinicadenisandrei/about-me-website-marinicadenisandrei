Delivered cloud-native platforms from low-level network design through high-velocity application delivery, combining hands-on engineering with architecture leadership.

**Enterprise CI/CD and release engineering.** Architected and implemented multi-cloud pipelines (on-premise, Azure DevOps, GitHub Actions, GitLab CI/CD) with build agents, parallelised test runners and gated releases. Blue/green and canary deployments through FluxCD/ArgoCD and feature flags (LaunchDarkly), with integrated SAST/DAST (SonarQube, OWASP ZAP), container-image scanning (Clair, Aqua) and compliance gates. Templated YAML pipelines and parameterised Terraform modules for self-service delivery.

**Cloud-native and infrastructure architecture.** Led adoption of AKS/EKS/GKE clusters configured with Calico CNI, network policies, Pod Security and OPA Gatekeeper, with lifecycle managed through Helm, Kustomize and Rancher. IaC blueprints in Terraform, Pulumi and ARM/Bicep for resource groups, VNET peering, AWS Transit Gateways, VPN tunnels and hybrid ExpressRoute. Service mesh (Istio, Linkerd) for mutual TLS, traffic routing and distributed tracing.

**Software and network architecture.** Domain-driven microservices, event-driven CQRS/ES (Kafka, Event Grid), serverless functions and API gateways (NGINX, Kong). Architecture reviews with C4/UML models; chaired Architecture Review Board sessions aligning teams on scalability, reliability, cost and compliance (GDPR, PCI-DSS). Multi-region VPC/VNET topologies with BGP failover, transit hubs, Azure Front Door / AWS ALB-NLB and CDN integration.

**Reliability engineering.** Chaos engineering (Chaos Mesh, Gremlin), synthetic monitoring (New Relic, Datadog), SLIs/SLOs/SLAs, capacity planning with HPA/VPA and Cluster Autoscaler, DR game-days, on-call rotations, runbooks and post-mortems with PagerDuty/Opsgenie alerting.

**Teams.** Code and design reviews, mentoring on TDD/BDD and pair programming, Scrum/Kanban workflows in Jira, PI planning and retrospectives.
