## VR and game development

Therapeutic mini-games in Unity (C#) (object reach, balance, gait training and coordination) with OpenXR, Oculus/Quest SDKs and Windows Mixed Reality support. Custom data-stream handlers for EEG sensors (Emotiv, OpenBCI), FES controllers and haptic gloves synchronise visual, audio and tactile feedback. State-machine-driven exercise workflows adjust difficulty dynamically from patient performance metrics.

## Analytics

Movement-analysis algorithms (Kalman filtering, ML classifiers) for fatigue detection and motor-pattern recognition, developed with neuroscientists; telemetry dashboards (Unity Analytics, custom WebGL) so clinicians can monitor session quality, success rates and adherence.

## Architecture and integrations

Modular Unity packages and ScriptableObjects for rapid prototyping of new therapy modules; REST and WebSocket APIs in ASP.NET Core for user profiles, session logging and remote progress tracking; OAuth2/SAML authentication and GDPR-compliant AES-256 encryption.

## DevOps

- **CI/CD**: GitLab CI runs Unity PlayMode/EditMode tests, asset validation and platform builds (Windows, Android APK, WebGL); Jenkins and TeamCity agents for parallel builds and smoke tests.
- **Containers**: session manager, analytics API and notification service as Docker micro-services on AKS, released with Helm across dev/test/prod.
- **IaC and secrets**: Terraform modules for Azure and AWS (VPCs, Azure SQL / RDS, storage, load balancers); Ansible and HashiCorp Vault.
- **Observability and security**: Prometheus/Grafana health and performance alerting, ELK with Kibana dashboards; Snyk and SonarQube gates in CI; RBAC across Git repositories and Kubernetes namespaces.

## Diorama exergame on Meta Quest 3

A rehabilitation game in which patients rebuild a 3D diorama piece by piece, in several themed worlds.

- **Clinical control.** The therapist sets up the session from the TRAVEE platform (world, diorama, starting point, music, distance and height) and can adjust it in real time; only the affected part of the scene is rebuilt, behind a loading screen.
- **Precision grasp.** Besides touch-to-grab, a thumb-and-index pinch mode with three precision levels and an on-screen guide that shows when the grip is close enough. Each piece can only be taken with the hand it was meant for, so left, right or alternating sessions train the right limb.
- **Motivating feedback.** The target spot pulses, and every placed piece brings back part of the surrounding world, from the horizon towards the patient, so effort has a visible result.
- **Progress data.** After each piece the therapist sees completion, timing and the hand used; at the end the platform receives a full record of the session, so sessions can be compared over time.
- **Home use.** A gaze-selectable stop button that follows the field of view, end-of-game panels that always stay visible, and headset recentring kept in sync with the game.
- **Performance on Quest 3.** Editor tools that profile draw calls, triangles and shadows from each starting point, then colliders, shadows, LOD groups, occlusion culling, batching and texture limits, plus runtime visibility and distance culling, for smooth rendering of detail-heavy worlds.
