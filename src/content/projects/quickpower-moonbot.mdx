## Context

MoonBOT is QuickPower's signal system for the intraday (IDM) and imbalance energy markets in Romania.

## Platform

- **Services**: a Flask web app served by gunicorn, a Playwright scraper for the Transelectrica live generation mix, a DAMAS market-data fetcher and a generation-mix monitor, all on PostgreSQL in Docker Compose.
- **Live market**: intraday trades, VWAP and price trends per product, live positions and the generation mix refreshed every few seconds.
- **Outage detection**: per-source monitoring of the generation mix that flags a sudden fall in output, cross-checked with official ENTSO-E unavailability notices, with notifications in every admin page.
- **Imbalance Watch**: predicts surplus or deficit for the next ten quarter-hours; models are retrained from the dashboard on data the platform collects itself.
- **Client reports**: per-client reports rebuilt from the assigned trader's live positions and republished automatically.

## Delivery

QA and production run as separate Compose stacks on the same server. GitHub Actions lints the code, builds the images and validates the compose file, then deploys QA on every push and production on tagged `RELEASE` commits over Tailscale.
