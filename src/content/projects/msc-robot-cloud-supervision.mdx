## Thesis

*Design, programming and control of industrial robotic processes, implementing a real-time control system for intelligent and cognitive control of robots, industrial processes, network, system security, and cloud supervision.*

## Hardware architecture

1. **Main Arduino** — directly connected to the robot and responsible for controlling its four servos (four axes).
2. **Diagnostics Arduino** — connected to the main board over I²C; generates system diagnostics, monitors sensor values of the industrial application and can shut the system down in critical scenarios.
3. **Error-handling Arduino** — connected over I²C; displays errors from the whole application.
4. **Raspberry Pi (Ubuntu)** — the two slave boards and an Arduino Mega with three SPI screens are attached to it. Python scripts retrieve diagnostics and errors and store them in an **AWS S3** bucket.
5. **AWS EC2** instances read the stored data and display it locally on the three screens (robot status, diagnostics, errors).

## Software

- Desktop application with command-line and graphical interfaces for supervision and control; user login requires approval from an admin application running on Linux.
- Web application with username/password authentication and two-factor authentication.
