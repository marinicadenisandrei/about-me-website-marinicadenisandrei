## What it does

- On-demand video courses and live webinars.
- Structured certification paths with assessments, digital badges and certificates.
- Role-based access for Administrators, Trainers and Ambassadors.
- Discussion forums, threaded comments, real-time notifications (WebSockets), private messaging and study groups.

## Platform

Same architecture family as [GLOBE-CoP](/projects/globe-cop): Node.js/Express core, Python/Flask micro-services, hybrid relational + document storage with Redis caching, Docker + Helm on Kubernetes (AWS EKS / GCP GKE), Terraform + Ansible infrastructure, CDN delivery for video, and ELK / Prometheus / Grafana observability.
