## On-board computer software

- Layered, modular firmware (secure bootloader, RTOS kernel, middleware and flight application) tailored to CubeSat avionics.
- FreeRTOS/Zephyr integration for deterministic scheduling and inter-task communication over I²C, SPI, UART and CAN.
- CCSDS-compliant telemetry/telecommand services with error detection, retry logic and configurable timeouts for reliable up/downlink.

## Embedded CI/CD and ground segment

- Dockerised ARM toolchain with Nexus/Artifactory artifact management.
- Jenkins and GitLab CI pipelines: Cppcheck and Clang-Tidy static analysis, Unity/Google Test unit tests, gcov/lcov coverage, nightly builds and merge-request validation; Ansible deployment to lab benches with rollback and Slack/Teams + Grafana feedback.
- GitOps guardrails: protected branches, mandatory peer-reviewed merge requests, pre-commit clang-format, semantic-version tagging; pytest + CMake smoke, regression and fuzz suites for the telecommand parsers.

## Infrastructure and security

Terraform + Ansible for Debian/Fedora build farms, staging environments and VPN gateways; Trivy/Clair image scanning, SSH key-only auth with port knocking, SELinux/AppArmor confinement, nftables, and OpenVPN/IPsec with VLAN segmentation isolating development, test and payload networks.

## Hardware-in-the-loop bench

As Full-Stack Developer, a reservation platform (Flask backend, React frontend) with SSO, role-based access and live status of multiple embedded boards; QEMU hardware emulation with fault injection for validation before hardware access; HIL regression suites orchestrated with Jenkins + Docker Compose covering sensor simulation and mock telemetry.

## Observability and anomaly detection

Fluentd logging and Prometheus metrics across OBC and ground-station subsystems, Grafana dashboards, Alertmanager SLA/SLO rules; Python (pandas, scikit-learn) models trained on historical telemetry to flag subsystem drift early. Living documentation in Doxygen and Sphinx/ReadTheDocs with Conventional-Commit changelogs.
