## Context

SIMPATIC is a PNRR-funded project that runs continuing-education programmes. Each participant needs a signed file before receiving a certificate, and the platform replaces the paper process.

## Participant flow

1. **Data**: pre-filled from the project records; missing fields are completed by the participant and protected fields can only be flagged for correction.
2. **Signature**: drawn once and applied to each document when it is signed.
3. **ID document**: uploaded as an image or PDF.
4. **Documents**: each annex is previewed as a PDF generated from the current data; changing the data invalidates earlier signatures.
5. **GDPR consent**: recorded with date, time and signature, and stored as its own PDF.
6. **Confirmation**: once everything is signed, the data is locked and the certificate becomes available.

## Administration

Filters by programme, status and county; a full file per participant with every document; editing with or without re-signing; and ZIP archives per participant or for any filtered selection, generated as a stream.
